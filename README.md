# Calc by Sameer Ahmed

Calc by Sameer Ahmed is a free online calculator website made for Economics, Computer Science, and Data Science students. It brings useful calculators for everyday study into one place, including GPA, Statistics, AP & GP Series, Basic Math, and Economics calculators.

**Live Website:** [Calc by Sameer Ahmed](https://sameer-ahmed1.github.io/Calc-by-Sameer-Ahmed/)
